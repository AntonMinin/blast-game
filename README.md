# Blast Game

Тайловая blast-игра на Cocos Creator 2.4.15 (TypeScript). Сцена — `assets/Scene/Game.fire`.

Физический движок не используется: падение тайлов и все анимации сделаны через `cc.tween`, а модули `Physics`, `Collider` и `3D Physics` исключены из сборки в настройках проекта.

## Правила

- Клик по группе из `minGroupSize` и более соседних тайлов одного цвета сжигает её.
- За каждый сожжённый тайл начисляется `pointsPerTile` очков, ход тратится.
- Тайлы сверху падают на освободившиеся места, пустоты заполняются новыми.
- Победа — набрать `targetScore` очков, поражение — закончились ходы (`maxMoves`).

### Перемешивание

Если на поле нет ни одной группы из `minGroupSize` тайлов и ни одного супер-тайла, поле автоматически перемешивается. За партию доступно `maxShuffles` перемешиваний; если их не осталось, а ходов по-прежнему нет, это поражение («Нет доступных ходов»).

### Бустеры

Бустер выбирается кликом по кнопке внизу экрана (активная кнопка пульсирует, повторный клик отменяет выбор). Бустеры не тратят ход, очки за сожжённые бомбой тайлы начисляются.

- **Бомба** (`bombCount`, `bombRadius`) — клик по полю сжигает тайлы в радиусе R от клетки.
- **Телепорт** (`teleportCount`) — клик по первому тайлу выделяет его, клик по второму меняет их местами.

### Супер-тайлы

Если сожжённая группа больше `superTileThreshold` тайлов, на месте клика появляется супер-тайл случайного типа. Клик по нему тратит ход и сжигает:

| Тайл | Действие |
|------|----------|
| Горизонтальные ракеты | всю строку |
| Вертикальные ракеты | весь столбец |
| Бомба | тайлы в радиусе `superTileRadius` |
| Ящик динамита | всё поле |

Супер-тайл, задетый чужим взрывом или бомбой, сгорает без активации.

Радиус R — квадрат со стороной 2R + 1 с центром в клетке (R = 1 — это 3×3), обрезанный границами поля.

Все параметры настраиваются в инспекторе компонента `BoardController` на узле `Canvas/BoardBackground/Board`.

## Архитектура

Логика игры и отображение разделены: классы логики не импортируют ничего из движка, а классы отображения не принимают игровых решений.

**Логика** (чистый TypeScript, покрыта тестами)

| Файл | Ответственность |
|------|-----------------|
| `assets/Script/BoardModel.ts` | Сетка тайлов: группы, области (строка, столбец, радиус, поле), обмен, перемешивание, гравитация. Строка `0` — нижняя. |
| `assets/Script/GameSession.ts` | Правила партии: ходы, очки, бустеры, супер-тайлы, перемешивания и результат. Каждое действие (`tryMove`, `tryBomb`, `trySwap`) возвращает описание того, что произошло, для отображения. |
| `assets/Script/BurnArea.ts` | Области сжигания за общим интерфейсом `BurnArea`: `RowArea`, `ColumnArea`, `RadiusArea`, `WholeBoardArea`. Используются супер-тайлами и бомбой; новый тип взрыва добавляется новым классом без изменения `GameSession`. |

**Отображение** (Cocos Creator)

| Файл | Ответственность |
|------|-----------------|
| `assets/Script/BoardView.ts` | Тайлы на поле: появление, волна сжигания от места клика, падение, телепорт, перемешивание. |
| `assets/Script/TileView.ts` | Анимации одного тайла: `dropIn`, `burn`, `fallTo`, `teleportTo`, `shuffleTo`, выделение, `wobble` на неверный клик, пульсация супер-тайла. |
| `assets/Script/BoosterPanelView.ts` | Кнопки бустеров: счётчики, неактивное состояние, пульсация выбранного бустера. |
| `assets/Script/HudView.ts` | Счётчик очков с отсчётом и «пружинкой», ходы краснеют, когда их мало. |
| `assets/Script/ResultPopup.ts` | Экран победы/поражения. |

**Связующее звено**

| Файл | Ответственность |
|------|-----------------|
| `assets/Script/BoardController.ts` | Передаёт клик в `GameSession`, результат хода — в `BoardView` и `HudView`, по окончании партии открывает `ResultPopup`. |

Длительности и параметры анимаций вынесены в константы в начале файлов отображения.

## Проверки кода

```
npm install
npm run typecheck
npm test
```

- `npm run typecheck` (`tools/check-code.js`) — строгая проверка TypeScript (`strict` в `tsconfig.json`) и запрет `any` и приведения типов `as` в `assets` и `tests`. Декларации движка (`creator.d.ts`) не проверяются.
- `npm test` — тесты логики модели и сессии без движка.

Cocos Creator 2.4 при компиляции только отбрасывает типы и запускает код даже с ошибками TypeScript. Поэтому проверка встроена в редактор расширением `packages/typecheck`:

- при открытии проекта и после каждого изменения `.ts`-файла запускается `npm run typecheck`, результат выводится в консоль редактора;
- **превью** использует страницу `preview-templates`: пока проверка идёт или есть ошибки, игра не запускается, а вместо неё показывается список ошибок; после исправления страница перезагружается сама;
- **сборка** останавливается на шаге `before-change-files`, если есть ошибки.

Для работы расширения нужен установленный TypeScript (`npm install`).
